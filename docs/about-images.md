# Home About images

Created with the built-in imagegen tool for the three-card About composition. These are generated editorial illustrations of a product studio, rather than photographs of VersaNex personnel.

All final assets are 900 x 1200 pixels (3:4 portrait), saved as WebP:

- [Left: design](../public/home-about-left-v2.webp)
- [Middle: collaboration](../public/home-about-mid-v2.webp)
- [Right: digital product](../public/home-about-right-v2.webp)

The original uploaded PNG files remain available. The homepage now uses the v2 assets on desktop and mobile. White borders separate the cards; smaller desktop cards and a wider fan keep them within their column. The scroll thresholds and mobile reveal timing remain unchanged.
