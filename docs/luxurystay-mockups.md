# LuxuryStay project showcase

Source website: https://luxurystay.versanex.site/. Actual homepage, rooms, services, and about screens were captured at desktop and mobile sizes on October 19, 2026 with `artifacts/capture-luxurystay.mjs`.

Five device scenes were generated using the built-in imagegen tool with the actual screenshots as screen references. These are generated device mockups. The coordinated direction uses ivory limestone, a cream backdrop, soft daylight, silver laptops and monitor, and a graphite phone to complement the website's black-and-amber identity.

Final assets: `public/mockups/luxurystay/`, exported at 1536 × 1024 as quality-92 WebP. The existing `public/clients-logo/LuxuryStay.png` supplies the project logo.

The complete final prompt set and generated source paths are saved in `artifacts/luxurystay/generated-manifest.json`. Export with `artifacts/export-luxurystay-mockups.mjs`.

The project is registered in `data/project-media.js` and the project navigation menu. Route: `/projects/luxurystay`. Existing public listing, homepage, service projects, metadata, and sitemap integrations consume the shared project data. Copy describes the observed public website without invented business results or technology claims.

Browser verification: `artifacts/check-luxurystay.mjs`. Screenshots and verification output are saved under `artifacts/luxurystay/`.

Verified at 1440, 390, and 320 pixels: all five mockups decode, no horizontal overflow, correct project metadata, two working live-site link targets, and no browser runtime errors. The desktop project menu includes LuxuryStay, and the live public projects API and project listing include the new entry. Local database access required running the preview server with network permission.
