# Fixit app mockups

Eight photorealistic smartphone scenes created with the built-in imagegen tool from the existing Fixit project screenshots. The mockups use pale ice-blue studio surfaces, natural daylight, realistic graphite and silver hardware, and the original navy, white, and teal app interface.

Final assets: `public/mockups/fixit/`. Original app screenshots: `artifacts/fixit/screens/`. Generated originals, prompt set, and source paths: `artifacts/fixit/` and `artifacts/fixit/generated-manifest.json`. These are generated mockups using existing app screens, not photographs of a running app on purchased devices.

Scenes cover the home dashboard, provider cards, service categories and packages, photo-based AI recommendations, appointment configuration and confirmation, provider messages, user profile, and a three-phone app overview. Source screenshot prices and names are demonstration data and are preserved in the images.

The public Fixit record in `data/project-media.js` uses the new mockups across the existing project card and case-study layout. Original database images remain available in the admin record. The route remains `/projects/fixit-your-ai-powered-home-services-companion`.

Export: `artifacts/export-fixit-mockups.mjs`. Browser checks: `artifacts/check-fixit.mjs`; report: `artifacts/fixit/verification.json`.
